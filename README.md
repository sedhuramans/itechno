# Itechno 2026 - Takshashila University

Itechno 2026 is the official **Inter-College Technical Festival** hosted by **Takshashila University**. This platform showcases the flagship events, competitions, workshops, and team details organized as part of the fest.

## 🚀 Features

- **Dynamic Interactive UI**: Modern responsive design featuring galaxy animations, custom cursor, sound effects, and dark theme aesthetics.
- **Flagship Technical Challenges**: Details, rules, and registration for Hackverse, Codeathon, Tech Battle, Word Battle, Pictionary, Free Fire Squad Battle, and Reel Creation.
- **Event Schedule & Timeline**: Interactive node matrix calendar.
- **Team & Committee Directory**: Complete list of chief directors, media coordinators, and event leads.
- **Direct Online Registration**: Seamless Google Form registration integration.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (React 19)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 💻 Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
